# Exact metadata curation and exclusions

The frozen manifest has one row per dataset and expression library. GSM identifies the specimen, not a new independent observation each time an accession reuses it. `dataset + sample` is the unique row key. Missing variables remain empty; no aggregate demographic value is assigned to a specimen.

1. GSE151371: read `disease state` characteristic; map healthy control/trauma control/spinal cord injury to HC/TC/SCI. The archived parser has a title-prefix fallback, but the raw audit and final assignments are supplied for review. Sample labels concatenate group plus the zero-padded last integer in the title. Participant equals sample because every person has one draw. HC is reference; SCI/TC acute. Include all 58 samples.
2. GSE226238: take the library identifier before the first comma in GEO title. Subject is the exact `ID` plus digits prefix; group comes from the group characteristic. The characteristic historically labelled treatment is a visit label (Acute/3mpi/6mpi/12mpi), not therapy. Keep it as original annotation but clear actual treatment. Use v0/v1/v2/v3 mapping to acute/3m/6m/12m and validate against the count sample columns. Include 37 SCI observations and nine control samples. ID5, ID7 and ID9 lack final visits; do not impute. Complete-case sensitivity uses the remaining seven participants/28 samples.
3. Clinical linkage: use the verified published GSE226238 Tables 1/2 and frozen clinical_mapping_precheck; match GSM to expression subject/article ID, verify SCI/CTL and visit. Apply participant age/sex/baseline AIS/NLI to all matched visits, retain visit AIS/NLI where provided. Do not infer infection or therapy from visit labels. Tables and linkage sources accompany the reproducibility archive.
4. GSE293559: match exact library name to the 26 new GSM records. For libraries present in GSE226238, match case-insensitively to the exact original library plus GEO reanalysis relations; retain original GSM and mark reused. Propagate verified published clinical fields by original GSM. Ten SCI acute libraries and all nine CTL are reused; only 26 SCI are new. Do not assign a fictitious new-series GSM to reused specimens.
5. Main additional-cohort comparison: all 36 SCI and nine reused CTL. Partial-overlap comparison: drop the 10 SCI rows marked reused, retain all CTL (26/9). Same-platform comparison: GPL18573 only (31/9); combine with new-SCI rule for 21/9. No score reselection/restandardization occurs during these exclusions.
6. GSE177034: individual, pain group and timepoint characteristics define 98 participants with 196 paired samples (49 persistent/49 resolved). All are metadata audit only and excluded from revised signature inference. No 196-participant denominator is used.
7. Technical fields: retain declared platform, instrument, library protocol/selection and raw processing annotations. A GEO submission date is not a sequencing or processing date. Blank batch/RIN/actual processing fields mean unavailable, not absence of a technical effect. Constant fields cannot be estimated as adjustment covariates.

Executable sources: frozen R1 prepare_metadata.py; R2 metadata_r2.py. Every final row includes provenance, overlap and source fields. `GEO_metadata_full_audit.csv` preserves the raw annotations used for the audit.
