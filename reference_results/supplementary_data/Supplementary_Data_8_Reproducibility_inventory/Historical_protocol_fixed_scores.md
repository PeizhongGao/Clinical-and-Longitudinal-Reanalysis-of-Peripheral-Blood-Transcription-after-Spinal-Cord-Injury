# 固定样本模型比较：修订阶段分析方案

锁定日期：2026-10-12。此方案在本轮新增模型拟合前记录；既有结果已知，因此属于修订阶段的事后诊断，不是研究事前预设。

## 问题与分析单位

在GSE151371/ODC-SCI 405的SCI–创伤对照比较中，区分完整病例选择、加入协变量后的点估计变化、置信区间变化及少数对照的影响。每人一条记录，分析单位为参与者。首要诊断对象是冻结先天分量和淋巴细胞相关分量，balance为由两者相减形成的次要指标。

## 不变项与输入审计

- 直接沿用已有15+15冻结分数，及其原TC参考标准化尺度；不重新标准化任何子集，不重选基因、权重或阈值。
- 对照原冻结分数表核验每人三个分数，核验balance恒等式与一人一行；保存输入MD5及原模型重现结果。
- 沿用既有临床定义：sex的F/M分类；TBI和既往CNS病史的No/Yes/Unknown分类。Unknown保留为来源类别，不进行插补。
- 不加入SCI特有AIS/NLI，不加入无可用来源的感染、治疗或技术字段。

## 固定样本和模型

1. 原48人（38 SCI/10 TC）：未调整、年龄/性别模型，作为原结果锚点。
2. 完整临床43人（36 SCI/7 TC）：未调整、年龄/性别、完整临床模型。
3. 临床与采血时间完整41人（36 SCI/5 TC）：未调整、年龄/性别、完整临床、完整临床加采血时间模型。

完整临床模型：`score ~ group + age + sex + ISS + TBI + prior_CNS`。采血时间模型再加入`draw_hours`。组别系数始终是SCI减TC。连续协变量只做减均值处理以改善数值条件；所有模型使用同一48人输入的中心常数，评分本身不变化。每个固定子集内所有模型必须使用完全相同的样本ID。

## 推断与诊断

- 采用OLS点估计、HC3异方差稳健协方差、残余自由度的t参考分布、双侧P及点对点95% CI，与原评分敏感性实现保持一致。
- 报告每个子集/模型内三个分数的BH q，以便原结果重现；另对全部9个模型的18个主要分量P值报告全局BH敏感性。依赖、选择及事后分析不因此变成确认性检验。CI不作同时覆盖校正。
- 将点估计差、SE及CI宽度变化列为描述性诊断，不将模型间差异当作独立样本检验或因果分解。
- 检查设计秩、残余自由度、标准化设计条件数、组别VIF、杠杆、Cook距离、组别DFBETAS、残差QQ/拟合图；记录Shapiro和学生化Breusch–Pagan诊断。诊断P不用于结果导向地选择检验。HC3不解决小TC数、模型错设或缺乏可比性。
- 对43人完整临床、41人完整临床、41人加时间三个模型，逐一删除每名TC后重新拟合三个评分，报告全部估计和CI及最大变化。原全样本模型保留为主结果；不挑选有利删除方案。
- 对全部参与者输出影响诊断，区分最大设计杠杆发生在SCI还是TC。高杠杆筛查线仅提示检查，不作为排除标准。
- 汇总年龄、ISS、采血时间的组内分布与一维范围交集，以及类别计数。范围交集不是充分的多变量共同支持，也不触发新删样本分析。

## 解释规则与边界

固定子集未调整结果与48人结果的差别描述样本选择的影响；固定子集内加入协变量后的差别描述调整敏感性；区间变宽描述精度变化。各阶段变化依赖比较路径，不能转述为“多少比例由混杂造成”。ISS的调整目标及SCI/TC严重度可比性需明确，不能把ISS自动当作无争议因果混杂变量，也不为了显著而删除它。

不能由本轮证明SCI特异性、排除未测混杂、确认细胞内机制或获得独立队列验证。分数是在该发现队列中选出的，HC3和BH不校正选择偏差；结果属于敏感性描述。
