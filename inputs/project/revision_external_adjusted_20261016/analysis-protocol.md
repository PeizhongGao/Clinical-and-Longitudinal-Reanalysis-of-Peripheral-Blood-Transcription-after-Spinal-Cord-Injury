# 外部血液转录模块临床与组成补强方案

本方案于2026年10月16日、计算本轮效应之前锁定。原稿、此前外部模块及临床分析结果已知；这是修回阶段的探索性分析计划，不是原研究事前设定、盲法或公开预注册。保留历史包，不重新挑选原15+15名单或优化外部模块。

## 问题和对象

检查固定四个外部BTM M37.1、M163、M7.0、M223的SCI–TC关联在相同参与者内加入临床及组成变量后如何变化，并检查纵向时间变化是否依赖组成代理指标。使用已有published和exclude_original106两种定义，全部成员、覆盖规则及评分沿用既有锁定文件；不按新结果挑模块。统计单位为参与者；纵向样本由参与者随机截距关联。

## 固定样本临床比较

精确复用已有48人（38SCI/10TC）、43人（36/7）、41人（36/5）样本名单，不因新结局变化重新删人或插补。

- 48人：group；group+age+sex。
- 43人：上述两项及group+age+sex+ISS+TBI+prior_CNS。
- 41人：上述三项及加入draw_hours。
- 43人组成敏感性：临床模型分别加入CIBERSORTx中性粒及总T细胞两个标准化估计，或加入下述无直接基因重叠的两个标记均值。

共每种模块定义44个组别系数，两种定义88项。OLS系数，HC3稳健SE，残差自由度t参考95%区间和双侧P。中心化和组成标准化在每个固定集合内完成，不改变结局的原log单位。保存全部设计秩、杠杆值、组别VIF、残差、影响指标和异常；不因诊断改变主模型或删异常值。临床43与41完整模型对每个TC逐一删除重拟合作诊断，非新增独立验证或挑选较优结果。

## 组成标记与覆盖审计

使用既有官方MCP-counter中性粒和T细胞值作为第一种代理。第二种代理从同一公开标记表中同时排除四个已映射外部模块源定义的基因并集以及原30基因；两类标记对所有结局使用同一个排除并集。基因不按表达方向或P筛选，记录每个排除、可用成员和剩余覆盖。至少3个有效标记且占排除后唯一成员至少50%才估计；否则保留失败状态，不换标记或放宽规则。采用既有全矩阵处理尺度的标记算术均值，明确称修改后的标记均值而非原样官方MCP-counter或实测比例。此检查去除直接算式共享，不消除同一bulk表达来源的共变、测量误差或组成混杂。

发现矩阵使用现有完整处理后表达；纵向计数按既有NCBI归一化因子、同一GeneID注释合并symbol和log2CPM prior.count=0.5重建，不重新估计归一化或选择成员。核验外部模块均值与旧逐样本评分一致。

## 纵向模型

10名SCI、37次观察（急性/3/6/12月10/10/10/7），score~factor(time)+(1|subject)，REML及Satterthwaite自由度，报告三个later-minus-acute对比。每种定义分别拟合：基础、官方两个组成代理、无重叠两个代理、无重叠中性粒单独、无重叠T细胞单独、年龄、性别、基线AIS A/B与C/D。年龄、性别、严重度分别调整，不与组成一次堆叠。再做7名完整病例28观察的基础及无重叠双代理敏感性。两种定义共240个时间对比。保留奇异、收敛或设计失败标记，不悄悄更换模型；缺失访视不插补，缺失原因未知。

## 多重比较及报告

当前主要补强族预先确定为published定义的4个43人临床模型组别系数和12个全SCI无重叠双代理纵向对比，共16项BH校正。另报告每种定义每一固定集合/模型内4项BH及纵向每种定义/范围/模型内12项BH。全部88个发现系数、全部240个时间对比各作额外总族BH敏感性，不声称覆盖历史整个研究或发现后选择偏倚。失败检验保留NA和计划族大小。

所有效应、点态95%CI、P/q、n和非显著结果均输出；模块之间不是独立生物学重复。前后估计变化为描述性、路径依赖，不作因果分解或以显著性变化代替效应差异检验。不跨表达来源合并评分绝对尺度。

## 结果决定正文排序的规则

无论显著与否都将外部定义模块及新调整结果写入正文，原15+15保持探索性定位。仅在调整后的估计、区间及诊断支持时使用“在所检验敏感性中保留”表述；若创伤比较不稳健则将证据主线收缩到小队列纵向表达变化及其分析依赖。即使纵向残余显著也不声称细胞内机制、SCI特异性或独立验证。保留公共代码暂缓及不可用变量限制。
